# Domain Docs

This repo uses a single-context domain doc layout.

Before engineering skills explore or write specs, they should read:

- `CONTEXT.md` for canonical domain vocabulary.
- Relevant decision records in `docs/wayfinder/decisions/`.
- `docs/wayfinder/00-map.md` when the work touches accepted project decisions or current project direction.

Use glossary vocabulary in issue titles, specs, plans, proposals, and review notes. If a term conflicts with `CONTEXT.md`, surface the conflict instead of silently choosing a synonym.

If an output contradicts an accepted decision record, call that out explicitly and treat it as reopening a decision, not as ordinary implementation detail.

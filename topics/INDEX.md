# Topic Index

Этот индекс помогает найти Topic Workspaces в Working Knowledge Base.

Правила:

- Topic Workspaces живут по пути `topics/<subject>/<stable-slug>/`.
- Индекс является источником навигации, но не владельцем состояния темы.
- `Goal.md` остается источником истины для Topic State, Active Block, Block Status, Mastery Level, Learning Map, Completion Criteria и Next Actions.
- Если строка индекса расходится с `Goal.md`, верить `Goal.md` и обновить индекс.
- Multi-subject тема имеет один primary Subject в пути; остальные Subject указываются в `Related Subjects`.
